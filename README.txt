SERAI SIP WEBSITE — PETUNJUK SINGKAT

Isi folder:
- index.html  : struktur halaman website
- style.css   : desain dan tampilan responsif
- script.js   : tombol pemesanan WhatsApp
- README.txt  : petunjuk penggunaan

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder "seraisip_website" di Visual Studio Code.
3. Buka index.html dengan Live Server, atau klik dua kali index.html untuk membuka di browser.
4. Website memakai Google Fonts dan foto dari Unsplash, sehingga koneksi internet diperlukan agar semua elemen eksternal tampil.

WAJIB DIUBAH SEBELUM DIPUBLIKASIKAN
1. Buka file script.js.
2. Cari baris:
   const WHATSAPP_NUMBER = "6281234567890";
3. Ganti dengan nomor WhatsApp Serai Sip yang aktif, menggunakan format internasional tanpa tanda plus dan tanpa spasi.
   Contoh format Indonesia: 6281234567890
4. Simpan file. Semua tombol pemesanan akan membuka chat WhatsApp dengan pesan otomatis.

CATATAN
- Website dibuat berdasarkan konsep dalam PDF: Serai Tea Concentrate, botol konsep 250 ml, dan varian Citrus Serai, Lychee Serai, serta Honey Serai.
- Harga, stok, dan detail transaksi sengaja dikonfirmasi melalui WhatsApp karena belum dicantumkan dalam materi bisnis.
- Ilustrasi botol di bagian varian adalah ilustrasi desain menggunakan CSS, bukan foto kemasan final.
- Untuk dipublikasikan online, folder dapat diunggah ke GitHub Pages, Netlify, atau layanan hosting statis lainnya.
